Privacy

These pages do not include an analytics script, an account, or a contact form.

Nothing you choose on the list is sent to VELLURA Studios. The site does not set its own cookies.

The browser may store three preferences on this device: the language (bf-lang), the country (bf-region), and the amount (bf-budget). Those values stay on the device.

The pages are static files hosted on GitHub Pages. Opening a page is a request to that host so the file can load.
